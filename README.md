# Mauritanian Elections Analysis

Analysis of 2019 and 2024 Mauritanian presidential elections.

## Usage

```bash
# Install dependencies
pip install -r requirements.txt

# Run analysis
python scripts/run_2019_analysis.py
python scripts/run_2024_analysis.py
python scripts/run_poverty_analysis.py
```

Outputs are saved in `output/figures/` and `output/html/`.
